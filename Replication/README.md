## Application to Add Health Data
- The file `AddHealth.data.R` prepares the data for analysis. Specifically, it extracts data from the raw Add Health datasets, performs data cleaning, and saves the cleaned datasets.
- The file `AddHealth.estimation.R` uses the cleaned data to estimate the models (linear, quantile, and CES specifications). It produces the results shown in Tables 5.1 and 5.2, and Tables in Appendix D
- The file `AddHealth.keyplayers.R` reproduces the counterfactual analysis results presented in Figure 5.1
